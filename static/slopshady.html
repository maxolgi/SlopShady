Help

Overview

SlopShady is a real-time GLSL shader editor with AI integration, modulation routing, and live performance controls.

Multi-Layer System

Supports up to 8 shader layers that can be blended together.

  • Layer Selection: Click a layer strip in the mixer to select it for editing
  • Ctrl+1 to Ctrl+8 — Select layer 1-8 for editing

Voice System

Each layer has up to 4 polyphonic voices triggered via MIDI or on-screen keyboard.

  • Poly: Multiple simultaneous voices with voice stealing
  • Mono: Single voice, last-note priority
  • Glide: Mono with portamento between notes
  • MIDI: Note-on/off triggers voices, CC routes to modulation

Keyboard Shortcuts

  • Ctrl+S — Save full state to JSON file
  • Ctrl+Shift+S — Save shaders list only
  • Ctrl+F — Toggle fullscreen
  • Ctrl+M — Toggle layer mixer panel
  • Tab — Toggle UI panel visibility
  • Space — Pause/Play shader animation
  • Ctrl+Shift+Space — Start/Stop playlist
  • Ctrl+Shift+Backspace — Master reset (clear all settings)
  • Ctrl+Shift+R — Start/Stop recording
  • Ctrl+Insert — Start/Stop live stream
  • Ctrl+Shift+L — Show modulation matrix

Layers

  • 1–8 — Select layer
  • Ctrl+1–Ctrl+8 — Select layer
  • Shift+1–Shift+8 — Toggle layer enabled
  • Insert — Crossfade to selected layer
  • Delete — Switch to previous layer

Shader Navigation

  • + / = — Next shader/preset
  • - — Previous shader/preset
  • Shift+Delete — Delete current shader

Code Dials

  • q–m hold — Momentary dial (×2 while held)
  • Shift+key — Dial ×2
  • Alt+key — Dial ÷2
  • Alt+Shift+key — Reset single dial
  • Backspace — Reset all dials

Misc

  • ` / ~ — Toggle feedback
